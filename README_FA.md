# پروژه اندروید Crow — بدون واترمارک

این پروژه یک پوسته‌ی مستقل اندروید با Kotlin برای اجرای نسخه‌ی اصلی بازی است. فایل HTML اصلی از APK ارسالی استخراج شده (از نسخه‌ی 1.2 فقط چند خط اتصال به اپ اضافه شده) و در مسیر زیر قرار دارد:

`app/src/main/assets/www/index.html`


## نسخه‌ی LiveOps 1.4 — آپدیت خودکار و فصل‌های آنلاین

- شماره‌ی برنامه در این سورس `versionCode=4` و `versionName=1.4` است.
- هنگام اجرا، اپ از مسیر HTTPS روی IP سرور نسخه را بررسی می‌کند. در صورت انتشار APK تازه، صفحه‌ی بررسی/دانلود با نوار پیشرفت نمایش داده می‌شود.
- APK بعد از دانلود با SHA-256، نام بسته، شماره نسخه و امضای APK نصب‌شده بررسی می‌شود؛ سپس نصب‌کننده‌ی رسمی Android باز می‌شود.
- بعد از نصب موفق، برنامه‌ی جدید دوباره اجرا می‌شود. نصب بی‌صدا بدون تأیید کاربر ممکن نیست.
- بسته‌های فصل منتشرشده در پنل به‌صورت خودکار در شروع بازی دریافت، هش‌سنجی و در حافظه‌ی داخلی برنامه نصب می‌شوند.
- پرونده‌های ۹ تا ۱۶ در همین نسخه‌ی 1.4 ادغام شده‌اند؛ فصل‌های بعدی را می‌توان با ZIP از پنل اضافه کرد.
- دکمه‌های پشتیبان/بازیابی و پشتیبانی که روی صفحه‌ی اصلی بودند حذف شده‌اند. دکمه‌ی «فصل‌ها» برای مدیریت دستی بسته‌ها نگه داشته شده است.
- ارتباط شبکه فقط برای API آپدیت و بسته‌های فصل است؛ در صورت قطع بودن سرور، بازی محلی اجرا می‌شود.

**محدودیت انتشار:** کاربران نسخه‌های قدیمی که updater ندارند، باید یک‌بار APK نسخه‌ی 1.4 را دستی نصب کنند. برای آپدیت روی نصب فعلی، کلید امضای خصوصی همان نسخه لازم است؛ keystore در فایل ZIP ارسالی وجود نداشت. قبل از انتشار عمومی، APK را با keystore اصلی Release امضا و روی دستگاهی که نسخه‌ی قبلی روی آن نصب است آزمایش کن.

جزئیات راه‌اندازی VPS در `crow-server/README_FA.md` است.

## چه چیزهایی حفظ شده‌اند؟

- کد، گرافیک، فونت‌ها و صداهای تعبیه‌شده در HTML اصلی
- نام برنامه و آیکون لانچر استخراج‌شده از APK
- حالت افقی صفحه
- ذخیره‌سازی پیشرفت بازی از طریق `localStorage` (بازی از آدرس امن `https://appassets.androidplatform.net` با WebViewAssetLoader اجرا می‌شود)
- کنترل دکمه‌ی Back اندروید مطابق تابع `window.androidBack` خود بازی
- مکث و ادامه‌ی بازی هنگام رفتن برنامه به پس‌زمینه و بازگشت

## واترمارک

این پروژه از پوسته و Runtime سازنده‌ی HTML to APK استفاده نمی‌کند؛ یک Activity مستقل Kotlin، فایل HTML بازی را از دارایی‌های داخلی برنامه اجرا می‌کند. بنابراین واترمارک آن سازنده در این پوسته وجود ندارد. هسته‌ی بازی و گرافیک اصلی حفظ شده، اما فایل HTML برای ادغام پرونده‌های ۹ تا ۱۶، سازوکار بسته‌های فصل و حذف کنترل‌های اضافی صفحه‌ی آغاز تغییر کرده است.

## ساخت با Android Studio در ویندوز

1. ZIP را استخراج کن.
2. پوشه‌ی `Crow_Android_Project` را در Android Studio با گزینه‌ی **Open** باز کن.
3. JDK 17 یا بالاتر و Android SDK Platform 36 را نصب داشته باش.
4. صبر کن Gradle Sync کامل شود.
5. از منوی **Build → Build Bundle(s) / APK(s) → Build APK(s)** خروجی بگیر.

یا از ترمینال ویندوز در ریشه‌ی پروژه اجرا کن:

```bat
gradlew.bat assembleDebug
```

خروجی Debug در مسیر زیر ساخته می‌شود:

`app/build/outputs/apk/debug/app-debug.apk`

در اولین اجرا، Gradle باید بتواند Gradle 8.13 و وابستگی‌های Android Gradle Plugin را از اینترنت دریافت کند.

## نکات مهم درباره‌ی سورس و امضا

- APK فایل‌های HTML بازی را در خود داشت، اما سورس اصلی پروژه‌ی Gradle و Kotlin ابزار سازنده داخل آن نبود. به همین دلیل پوسته‌ی Kotlin از نو ساخته شده و این پروژه، بازسازی قابل‌ساخت بر اساس محتوای قابل‌بازیابی APK است؛ نه نسخه‌ی اصلی پروژه‌ی سازنده.
- محتوای بازی در این پروژه همچنان HTML/Canvas داخل WebView است. این کار منطق و ظاهر فعلی بازی را حفظ می‌کند و به معنی تبدیل کد بازی به UI کاملاً Native نیست.
- فایل خصوصی `.p12` داخل ZIP قرار داده نشده تا کلید امضای برنامه افشا نشود. APK دیباگ با کلید تستی Android امضا می‌شود؛ برای نصب به‌روزرسانی روی نسخه‌ی فعلی، باید خروجی Release را با همان کلید امضای قبلی امضا کنی. در غیر این صورت ممکن است لازم باشد نسخه‌ی قبلی را حذف و نسخه‌ی جدید را نصب کنی.

## سیستم فصل‌ها — نسخه 1.3 و گسترش LiveOps در 1.4

- دکمه‌ی **مدیریت فصل‌ها** به صفحه‌ی آغاز اضافه شده است.
- فصل‌های تازه همچنان می‌توانند به‌صورت فایل ZIP و بدون حساب کاربری به‌صورت دستی وارد شوند. نسخه‌ی 1.4 علاوه بر این روش، دانلود خودکار بسته‌ها از سرور HTTPS را هم اضافه کرده است.
- بسته‌ها در حافظه‌ی خصوصی برنامه ذخیره می‌شوند و هنگام اجرای بازی، قبل از شروع، بارگذاری می‌شوند.
- هر بسته می‌تواند چند مرحله، صحنه، سرنخ، دیالوگ، شخصیت، کنش و پایان جدید اضافه کند.
- نصب مجدد یک بسته با همان شناسه، نسخه‌ی آن را جایگزین می‌کند و ترتیب نصب قبلی را حفظ می‌کند.
- فایل‌های بسته در مسیر خصوصی برنامه استخراج می‌شوند؛ مسیرهای خطرناک ZIP رد می‌شوند و برای تعداد و اندازه‌ی فایل‌ها سقف وجود دارد.
- فایل‌های ZIP باید از منبع مورد اعتماد باشند؛ اسکریپت فصل داخل محیط بازی اجرا می‌شود و می‌تواند به منطق بازی دسترسی داشته باشد.

### واردکردن فصل جدید در گوشی

1. فایل ZIP فصل را روی دستگاه ذخیره کن (مثلاً از تلگرام یا با کابل USB).
2. بازی Crow را باز کن و در صفحه‌ی اول روی **مدیریت فصل‌ها** بزن.
3. گزینه‌ی **افزودن / به‌روزرسانی فصل** را انتخاب و ZIP را وارد کن.
4. بازی خودش دوباره بارگذاری می‌شود و مراحل فصل در دفترچه‌ی پرونده‌ها ظاهر می‌شوند.

### ساختار بسته‌ی فصل

در ریشه‌ی ZIP باید `pack.json` و فایل JavaScript معرفی‌شده در `entry` قرار بگیرند. نمونه‌ی قابل‌استفاده و راهنمای API در فایل `Crow_Season_Template.zip` و `CROW_SEASON_PACKS_FA.md` ارائه شده‌اند.

**محدودیت مهم:** اگر سرور در دسترس نباشد، واردکردن دستی ZIP همچنان کار می‌کند؛ اما دانلود خودکار ممکن نیست. پس از نصب یک بسته، برای افزودن فصل‌هایی که فقط از API فعلی موتور استفاده می‌کنند، نیازی به APK جدید نیست. اگر فصل به قابلیت یا کد موتور تازه‌ای نیاز داشته باشد که در این نسخه‌ی بازی وجود ندارد، ابتدا باید APK به‌روزرسانی شود.

## تغییرات نسخه 1.2

- در نسخه‌ی 1.2 دکمه‌های **پشتیبان** و **بازیابی** برای خروجی/ورودی گرفتن از فایل ذخیره اضافه شده بودند؛ در نسخه‌ی 1.4 کنترل‌های پشتیبان/بازیابی و پشتیبانی از صفحه‌ی اول حذف شده‌اند.
- لرزش هنگام پیدا کردن سرنخ، افشای مهم و پایان بازی (از طریق `window.CrowNative`).
- روشن ماندن صفحه هنگام بازی.
- اگر پردازش WebView کشته شود، بازی دوباره ساخته می‌شود و برنامه نمی‌بندد.
- مکث خودکار هنگام تماس/تغییر Audio Focus و درآوردن هدفون.
- Splash مشکی با لوگو در Android 12+ و آیکون Monochrome (تم Material You) در Android 13+.
- فایل `PRIVACY_POLICY_FA.md` برای انتشار در بازارها.
- **توجه:** برای دکمه‌های پشتیبان/بازیابی و لرزش، `index.html` دیگر «دست‌نخورده» نیست؛ فقط چند خط اضافه شده که بیرون از اپ اندروید (مثلاً در مرورگر) هیچ اثری ندارند.

## تغییرات نسخه 1.1

- رفع خطای `gradlew`: کلاس داخل `gradle-wrapper.jar` با نام پکیج اشتباه (`com.crown`) ساخته شده بود؛ jar از روی `tools/GradleBootstrap.java` دوباره ساخته شد.
- جایگزینی `kotlinOptions` (حذف‌شده در Kotlin 2.2) با `compilerOptions`.
- `targetSdk` برابر 36 شد و بازگشت (Back) با `OnBackInvokedCallback` (Predictive Back) پیاده شد.
- حذف مجوزهای `INTERNET` و `ACCESS_NETWORK_STATE`؛ بازی کاملاً آفلاین است.
- استفاده از `WebViewAssetLoader` و `allowFileAccess = false` به‌جای `file://`.
- حالت تمام‌صفحه‌ی immersive، پشتیبانی از ناحیه‌ی Cutout، و چرخش افقی در هر دو جهت.
- `allowBackup` خاموش شد.
- آیکون Adaptive (پس‌زمینه‌ی مشکی + تصویر کلاغ) برای Android 8 به بالا.
- امکان امضای Release با فایل `keystore.properties` (پایین را ببین).

> توجه: چون آدرس اجرای بازی از `file://` به `https://appassets.androidplatform.net` تغییر کرده، `localStorage` جدا از نسخه‌ی قبلی است و پیشرفت ذخیره‌شده‌ی نسخه‌ی 1.0 منتقل نمی‌شود.

## ساخت نسخه‌ی Release امضاشده

1. فایل `keystore.properties` را در ریشه‌ی پروژه (کنار `gradlew`) بساز:

```properties
storeFile=C:/path/to/your-key.p12
storePassword=رمز-keystore
keyAlias=نام-alias
keyPassword=رمز-کلید
```

2. اجرا کن: `gradlew.bat assembleRelease`
3. خروجی: `app/build/outputs/apk/release/app-release.apk`

این فایل در `.gitignore` است؛ آن را و کلید خودت را جایی منتشر نکن. اگر فایل وجود نداشته باشد، APK Release بدون امضا ساخته می‌شود.
